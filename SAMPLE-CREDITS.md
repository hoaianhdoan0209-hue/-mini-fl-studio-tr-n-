# Audio sample credits — Mini FL Studio V1.3

Real recorded instrument samples (embedded MP3, encoded as JavaScript Base64) are from:
- **[tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments)** by Nicholaus P. Brosowsky and original sample contributors.
- Samples license: **Creative Commons Attribution 3.0 (CC BY 3.0)**. https://creativecommons.org/licenses/by/3.0/
- Source information: https://github.com/nbrosowsky/tonejs-instruments/blob/master/sample-source-info.txt

The embedded samples are:
- **Electric Guitar** — originally recorded by **Karoryfer Samples**, distributed and edited through tonejs-instruments; source folder `samples/guitar-electric` (A3, C4, C5, A5). Played with independent pitch shifting. The Drive preset also applies non-destructive DSP waveshaping.
- **Acoustic Guitar** — **University of Iowa Electronic Music Studios** sample collection, via tonejs-instruments; `samples/guitar-acoustic` (A3, F4, C5).
- **Nylon Guitar** — Freesound contributor **quartertone**, sample set `11573__quartertone__classicalguitar-multisampled`, via tonejs-instruments; `samples/guitar-nylon` (A3, E4, A5).
- **Piano** — **Versilian Studios**, VSCO 2 Community Edition (VSO2), via tonejs-instruments; `samples/piano` (A3, A4, A5).

The audio files were not altered before bundling; they are compressed MP3 recordings encoded as Base64. Playback changes pitch, gain and envelope using Web Audio; optional guitar drive changes timbre during playback. The project does **not** include any copyrighted recording, riff, stem, or sample from Wxrdie or another commercial music track.

Drums, trap 808, ambient pads, synth, bell and FX remain locally generated by Web Audio oscillators/noise, rather than falsely labeled as sampled instruments.

This attribution must accompany redistributed copies of the included recorded sample banks. Code is independently authored for Mini FL Studio. For the full terms and proper attribution, see the upstream sample repository and license.
